CLASS 02 OF 05

CausalSelfAttention

The "talk" phase. Students turn around, read each other's cards, update their notes.

(B, T, C) → (B, T, C)
CausalSelfAttention — step 1

Compute Q, K, V — one matrix, three outputs

# One linear layer, 3× wider output self.c_attn = nn.Linear( config.n_embd, 3 * config.n_embd, bias=False ) # In forward() — split into Q, K, V q, k, v = self.c_attn(x).split( self.n_embd, dim=2 ) # each shape: (B, T, 384)
Q
Query — "what am I looking for?"
Matched against every other token's Key
K
Key — "here's what I am"
Compared against the querying token's Q
V
Value — "here's what I'd share"
Blended together weighted by attention scores
CausalSelfAttention — step 2

Split into heads — the reshape

head_size = C // self.n_head # 384 // 6 = 64 dims per head # (B, T, 384) → (B, 6, T, 64) q = q.view(B, T, self.n_head, head_size) .transpose(1, 2) k = k.view(B, T, self.n_head, head_size) .transpose(1, 2) v = v.view(B, T, self.n_head, head_size) .transpose(1, 2)
(B,T,384)
→ view →
(B,T,6,64)
→ T →
(B,6,T,64)
1
view() splits 384 dims into 6 heads × 64 dims each
2
transpose(1,2) moves head next to batch — each head now runs independently
CausalSelfAttention — step 3

Score, mask, softmax, blend

# Q × Kᵀ → scores (B, 6, T, T) att = (q @ k.transpose(-2, -1)) * (1.0 / math.sqrt(head_size)) # Hide future positions att = att.masked_fill( self.bias[:,:,:T,:T] == 0, float('-inf') ) # Softmax → weights summing to 1 att = F.softmax(att, dim=-1) # Weighted blend of Values y = att @ v # (B, 6, T, 64)
÷
Scale by √64 = 8 — prevents large scores from collapsing softmax into one winner
▲
-inf mask — future positions become exactly 0.0 after softmax. Students only read earlier seats.
∑
att @ v — each token receives a weighted blend of all earlier tokens' Values
CausalSelfAttention — step 4

Reassemble and project

# (B, 6, T, 64) → (B, T, 384) y = y.transpose(1, 2) .contiguous() .view(B, T, C) # Mix head outputs through learned layer y = self.resid_dropout(self.c_proj(y)) return y # (B, T, 384) — same as input
↻
transpose + view — 6 heads × 64 dims → one 384-dim vector again
!
.contiguous() required before .view() — transpose() only changes strides, not data layout
→
c_proj — the model learns which combinations of heads matter most
CLASS 03 OF 05

FeedForward

The "think" phase. Each token processes its notes alone. No communication with others.

(B, T, C) → (B, T, C)
FeedForward

Expand → Filter → Compress

class FeedForward(nn.Module): def __init__(self, config): super().__init__() self.net = nn.Sequential( # Expand: 384 → 1,536 (4×) nn.Linear(config.n_embd, 4 * config.n_embd, bias=False), # Filter: the non-linearity ★ nn.GELU(), # Compress: 1,536 → 384 nn.Linear(4 * config.n_embd, config.n_embd, bias=False), nn.Dropout(config.dropout), )
4×
Expand to 1,536 — more room to compute useful combinations of the gathered context
★
GELU is the critical line. Without a non-linearity the whole network collapses into one linear transformation.
↓
Compress to 384 — ready for the next block
56% of all parameters live here — 2× more than attention.
CLASS 04 OF 05

Block

One complete round. Attention + feed-forward, wrapped in LayerNorm and residuals.

(B, T, C) → (B, T, C)
Block

Five lines that do everything

class Block(nn.Module): def __init__(self, config): super().__init__() self.ln_1 = nn.LayerNorm(config.n_embd) self.attn = CausalSelfAttention(config) self.ln_2 = nn.LayerNorm(config.n_embd) self.ffn = FeedForward(config) def forward(self, x): # Talk + residual x = x + self.attn(self.ln_1(x)) # Think + residual x = x + self.ffn(self.ln_2(x)) return x # (B, T, C) — unchanged
ln
LayerNorm before each sub-layer — keeps values at a calm scale. Pre-norm (GPT-2 style) is more stable than post-norm.
+
x = x + sublayer(x) — students keep original notes and add new ones. Makes 6 stacked layers trainable.
Input shape = output shape = (B, T, C). That's why we can stack 6 of them.

Before we declare victory

Sanity check — loss should be ~8.32

x = torch.randint(0, 4096, (4, 64)) logits, loss = model(x, x) print(f"Logits: {logits.shape}") print(f"Loss: {loss.item():.4f}") # Expected: # Logits: torch.Size([4, 64, 4096]) # Loss: 8.3178
?
Why 8.32? Random model → equal probability for all 4,096 tokens. ln(4096) ≈ 8.32.
If you see ~8.32 → working. Very different → something is wrong.
