Step 01

Three views per token

Each token produces a Query ("what am I looking for?"), a Key ("what do I offer?"), and a Value ("what would I share?"). All three are learned during training.

Step 02

Score against every prior token

Each Query is dot-producted with every earlier Key. The result is a similarity score — how relevant each prior token is to the current one's question.

Step 03

Softmax + weighted blend

Scores become probabilities (summing to 1). The token's new representation is a weighted mix of all prior Values, with relevant tokens contributing more.

About these patterns: the six heads shown here aren't from a trained model — they're hand-crafted to mimic patterns found in real, trained transformers. After training, GPT-2's heads have been studied extensively: some attend to the previous token, some track subject-verb agreement, some focus on punctuation, and so on. The patterns here are illustrative; in your own trained 12 M model, the specializations will look similar but not identical.
